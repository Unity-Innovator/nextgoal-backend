# Registration and OTP
Registration uses a phone number and an OTP verification code. Enter your phone number on the registration screen, request an OTP, then enter the code on the verification screen. Verification must succeed before continuing with registration.

An OTP is a six-digit code. Keep any leading zero when entering it. If verification fails, check the number and code and use the resend option to request a fresh code. Do not share OTP codes, passwords, or PINs with the assistant.
